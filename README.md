# 竞品视频拆解卡

> 篝火出品 · 收录于篝火 App 应用区

输入视频，输出分镜、钩子、话术结构表

![界面截图](docs/screenshot.png)

## 下载

到 [Releases](https://github.com/campfire-code/video-breakdown/releases/latest) 下载对应安装包：

| 电脑 | 文件 |
|---|---|
| Windows 10 / 11 | `video-breakdown_版本号_windows-x64-setup.exe` |
| Mac（Apple 芯片） | `video-breakdown_版本号_mac-arm64.dmg` |
| Mac（Intel 芯片） | `video-breakdown_版本号_mac-x64.dmg` |

第一次打开：
- **Windows**：如果弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
- **Mac**：如果提示「无法验证开发者」，打开「系统设置 → 隐私与安全性」，在下方点「仍要打开」。

## 怎么用

本工具**不直接处理视频文件**：先用别的工具（如离线视频转字幕）拿到同行视频的字幕或文案，再来拆解。

1. 打开应用，在右上角「设置」里填自己的大模型接口地址、密钥和模型名（兼容 OpenAI 接口格式）。密钥只存在本机。
2. 在左边粘贴文案，或点「导入 .srt / .txt」、把文件拖进窗口。带时间轴的 .srt 能拆出每段时间和语速，纯文案不计算语速。
3. 可填视频标题或备注，可选发布平台（不指定 / 抖音 / 快手 / 视频号 / 小红书 / B 站），点「AI 拆解」。
4. 右边出现拆解卡：最上面是一条时间轴（分镜段、语速柱状图、转化点标记，只有带时间轴的字幕才有），下面是分镜结构、开头钩子、话术节奏、转化点、可以借鉴。首次打开显示的是带「示例」标记的示例结果。
5. 点「导出 Excel」得到 .xlsx 表格，点「导出图片」得到若干张 1080×1440 的 PNG 卡片；可先「选择保存位置」。

限制：正文超过 12000 字时只拆解前面部分，界面会提示；拆解只依据文字，画面部分只给建议。

## 验收用例

1. 导入 `samples/示例-折叠收纳箱带货.srt`：左下提示「识别为字幕」，显示条数、时长、字数、平均字/分钟。
2. 导入 `samples/示例-带饭口播文案.txt`：识别为纯文案，不显示时长和语速。
3. 导入 `samples/示例-只有时间轴.srt`：提示「看起来是字幕文件，但没有读到任何字幕内容」，「AI 拆解」按钮不可点。
4. 未填大模型接口时点「AI 拆解」：提示先到设置里填写，不会崩溃。
5. 填好接口后拆解收纳箱示例：右边出现钩子、分镜、话术节奏、转化点；点「导出 Excel」生成 .xlsx，点「导出图片」生成 PNG，文件夹里能打开。
6. 修改左边文案：右边出现「文案已修改，点『AI 拆解』更新」。

自动化测试覆盖字幕解析、语速统计、大模型回复容错解析（含格式不对时重试一次）、卡片排版分页、Excel 生成，全程使用假的大模型函数，不联网。

## 自己编译

需要 Node.js 22、pnpm、Rust。

```bash
pnpm install
pnpm test          # 单元测试
pnpm tauri dev     # 开发运行
pnpm tauri build   # 打包
```

界面框架在 `src/kit`（所有 campfire-code 工具共用），本工具的逻辑在 `src/tool`。
